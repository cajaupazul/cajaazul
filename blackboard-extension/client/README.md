# Cliente Chromium

El código fuente/ZIP de la extensión no estaba incluido en este repositorio y
el objeto remoto que usaba CampusLink ya no existe en R2.

Coloca aquí el contenido descomprimido de `campuslink-extension.zip`.

La extensión debe consumir el contrato HTTP estable de:

`https://campuslink-api.cajaupazul.workers.dev`

No depende del frontend de CampusLink. Cualquier otra extensión autorizada
puede utilizar los mismos endpoints y el mismo bucket R2 sin importar ni
reutilizar código de esta extensión.
